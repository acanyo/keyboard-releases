# keyboard 下载

keyboard 桌面软件的公开下载仓库，提供 Windows、macOS 和 Linux 安装包及版本更新说明。

## 下载最新版本

**[进入最新版本下载页](https://github.com/acanyo/keyboard-releases/releases/latest)**

| 系统 | 推荐安装包 |
| --- | --- |
| Windows 64 位 | `HanLinYueInstaller_<版本>_x64.exe` |
| macOS Apple 芯片（M 系列） | `HanLinYueInstaller_<版本>_arm64.zip` |
| macOS Intel 芯片 | `HanLinYueInstaller_<版本>_x64.zip` |
| Linux | `.AppImage`、`.deb` 或 `.rpm` |

下载页下方的 **Assets** 列出了对应版本的全部安装包。文件名保留 HanLinYue，软件显示名称为 keyboard。
